# QA Chatbox

A modern React web application built with Vite and React Router for real-time messaging and chat features.

## 🚀 Features

- **Splash / Loading Screen**: Animated QA splash screen experience.
- **Routing**: Multi-page navigation supported by React Router (`Home`, `Login`, `Signup`, `Message`, `Call`).
- **Responsive UI**: Clean typography using Poppins & Avenir Next fonts with custom CSS styles.

## 🛠️ Tech Stack

- **Frontend Framework**: [React](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Ali1972101/QAchatbox.git
   cd QAchatbox
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
